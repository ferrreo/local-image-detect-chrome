All inference runs inside Chrome using WebGPU or WASM. Image pixels never leave your machine after the optional one-time model download.

Default: ≤40.99% → Real, ≥69.51% → AI, between → uncertain (?). Bounty evaluation still scores at 65%. On-page badges show AI by default; enable Debug mode to also show Real / ?.

When Blur or Blank out is selected, click the red AI badge on a page to reveal that image (click again to hide).

Debug shows Real and uncertain (?) badges (and a pending … marker). Without it, images blur while scoring and only AI labels appear when done — anything not labeled AI unblurs.
